Бренд-ассеты

Центральная библиотека фирменных элементов efin для генерации и последующей сборки макетов. Рубрики управляют стилем, но их названия не выводятся на баннер автоматически. Агент должен использовать только реальные бренд-ассеты из Figma.

Логотипы

Использовать только оригинальные варианты логотипа efin из Figma. По умолчанию на баннере — один логотип, если иное не требуется по композиции.

Запрещено: самостоятельное перерисовывание, изменение формы знака и придумывание новых версий.

Декоративные элементы

Фирменные плашки, эмблемы и вспомогательные графические элементы используются как библиотека для рубрик и шаблонов.

Допустимо менять: масштаб, положение и плотность. Недопустимо менять: геометрию и фирменные цвета без согласования.

Правила для агента

  • Один основной логотип на макет по умолчанию.
  • Бренд-ассеты брать только из Figma-библиотеки.
  • Не дублировать логотип ради декора.
  • Не размещать название рубрики на баннере автоматически. Исключение — если оно явно указано в утверждённом тексте баннера.
  • Если нужен бренд-элемент, приоритет у фирменной графики, а не у повторения лого.

Новое поколение баннера

Промпт создаётся из задачи и настроек выбранной рубрики. Он не запускает нейросеть автоматически: экспортируй задание и загрузи полученный PNG/JPG как новую версию.

Пока это режим ручного импорта. Автоматическая генерация и Figma-экспорт потребуют серверного подключения. Старые варианты при добавлении новой версии не удаляются.
